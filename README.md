# Расписание — Саша (PWA)

Приложение-расписание РК6-55Б (осень 2026). Открывается как сайт
https://damirnine.github.io/sasha-planner/ и ставится на телефон как приложение.

## Установка на телефон

- **Android (Chrome):** открой сайт → кнопка «⬇ Скачать приложение» сверху
  (или меню ⋮ → «Установить приложение»).
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

## Что где хранится

- **Общие события** — `data/db.json` в этом репозитории (видны на обоих телефонах).
- **Личные события и галочки «сделано»** — только в памяти телефона (localStorage).
  «Обновить приложение» их не трогает. Резервная копия: Настройки → «Экспорт личного».

## Токен (для добавления/удаления общих событий)

1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token,
   доступ только к `sasha-planner`, Contents: Read and write.
   **Срок действия выбрать максимальный** (по умолчанию 30 дней). Когда токен истечёт,
   расписание продолжит обновляться, а в настройках появится «Токен: не подходит ✗» —
   тогда создать новый и повторить шаги 2–3.
2. На ПК в папке проекта: `node scripts/make-setup-link.mjs` → вставить токен.
   Появятся `setup-out/setup-qr.png` и `setup-out/setup-link.txt`.
3. Передать токен в **установленное** приложение:
   - **Android (Chrome):** навести камеру на QR — ссылка откроется в Chrome, и приложение,
     установленное из Chrome, получит токен.
   - **iPhone** (и Android с другим браузером): скопировать ссылку из `setup-link.txt`
     (например, отправить себе в «Избранное»), открыть приложение → Настройки →
     «Токен GitHub» → вставить ссылку целиком → «Сохранить токен».
   - В самом приложении проверить: Настройки → «Токен: установлен ✓».
4. Сделать на обоих телефонах, потом удалить папку `setup-out` и сообщение со ссылкой.

Токен никогда не хранится в репозитории.

## Разработка

```bash
python -m http.server 8000   # http://localhost:8000 — данные из ./data, общие правки только в памяти
npm test
```

Service worker на localhost выключен; включить: `http://localhost:8000/?sw=1`.
При каждом выпуске поднимать `VERSION` в `sw.js` и `APP_VERSION` в `js/version.js`.
